Como Usar

1
Escolha o Script
Selecione o script mais adequado para suas necessidades. Cada um tem um nível de dificuldade e impacto diferentes.
2
Copie o Comando
Clique em "Copiar Comando" para copiar o comando PowerShell para sua área de transferência.
3
Execute como Admin
Abra PowerShell como administrador e cole o comando. Confirme os prompts conforme necessário.

⚠️ Importante

Todos os scripts são de código aberto e verificados pela comunidade. Sempre faça backup de seus dados antes de executar scripts de sistema. Recomendamos criar um ponto de restauração do Windows antes de começar.
